Use Herdr to start one independent coding agent in a background sibling pane and ask it to review the current changes without modifying files. ${ARGUMENTS:-Focus on correctness, regressions, security, and missing tests.}

Wait for the reviewer, inspect its complete response, independently validate its findings, and report only actionable issues. Keep focus in the current pane and do not close panes you did not create.
